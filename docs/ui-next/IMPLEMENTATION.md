## Data and lifecycle contracts

- New operator lists use signed, filter-bound cursors, deterministic ID tiebreakers, `hasMore` and an observation context. Status remains current on each page; creation cutoffs are not claimed to freeze changing account or review state.
- Account actions read at most 30 accounts and 30 incident summaries per page. Account metadata reads do not invoke provider portfolio methods or return credentials, identity values or provider capability payloads. Filter pickers include retired accounts and preserve selected original IDs outside the current page.
- Cockpit reads global counts separately from up to 50 active positions/intents, 50 unknown orders, 30 risks/incidents and 100 account names. Its equity chart declares the 1,000-observation/90-day budget. Complete lists and trade details remain separately addressable. Original position money is never relabelled using today's account currency.
- MCP lists independently page 30 agents, proposals, sessions and actions. Selected-agent retrieval is independent of page membership; lists omit proposal and action blobs. Proposal review binds actual content, affected paths/accounts, preflight and expiry.
- Setup review binds the uploaded content and the entire affected current library, including unbound drafts. Large reviews use sections of 30 keys and 10,000 text units; source changes invalidate subsequent reads and apply. Preview storage has count, lifetime and input budgets.
- Stored signal text is read in 10,000-Unicode-character sections from SQLite. Ingress relationships, trade relations and account/history evidence have independent pages. Missing original decisions are not recreated from current settings.
- Durable UI jobs retain actor/scope/input binding and bounded receipts outside the restored database. An interrupted process leaves an unknown result requiring inspection; it never replays an order or delivery. Restart observes a new server instance without declaring trading healthy.
- Migrations 47 and 48 add graph draft revisions and original equity currency/source/mode. Historical unknown values remain unknown. Migration rewind fixtures preserve the added evidence before schema changes.
- Compatibility APIs remain available for existing builder/configuration consumers. They are not an unrestricted database, executor, file-path or shell interface. Published history, safety projections and provider acceptance are not directly editable.
